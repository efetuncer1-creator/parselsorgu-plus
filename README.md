# Parsel Sorgu +

TKGM parsel sorgulama, alan ve parsel analizi, eğim ve paftalı çıktı için Windows uygulaması.

**[Son sürümü indir](https://github.com/efetuncer1-creator/parselsorgu-plus/releases/latest)** → `ParselSorguPlus-Kurulum-x.y.z.exe` (Windows 10/11)

- Kurulum yönetici izni istemez. Yeni sürüm çıkınca uygulama kendisi haber verir.
- Kurulum dosyası henüz imzalı değil: Windows "bilgisayarınızı korudu" derse **Ek bilgi → Yine de çalıştır**.
- Tanıtım ve güncelleme notları: https://parselsorgu-plus.vercel.app

Bu depoda yalnız kurulum dosyaları yayınlanır.
